# Security policy

## Supported versions

Security fixes are applied to the latest `0.1.x` source release and the latest revision of `main`.
Distributions are retained as repository build artifacts and are not published to a package
registry.

## Reporting a vulnerability

Do not report vulnerabilities in public issues, discussions, or pull requests. Use GitHub's private
vulnerability reporting for this repository and include:

- the affected revision or version;
- the expected and observed behavior;
- reproduction steps or a minimal proof of concept;
- the potential impact;
- any suggested mitigation.

Reports are acknowledged after review. Details are kept private until a fix and disclosure plan are
ready.
