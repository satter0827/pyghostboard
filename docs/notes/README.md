# Notes

This directory holds temporary research, comparisons, and unresolved decisions. A note is working
material, not a supported contract or an operating procedure.

Name a note `YYYY-MM-DD-topic.md`, using lowercase ASCII words separated by hyphens. Record enough
context to resume the investigation, but do not copy established design into a note.

When a decision is implemented, move the resulting rule to the relevant
[design document](../design/README.md) and delete the note in the same pull request. Git history
preserves prior investigation, so this directory does not contain an archive.

Notes are excluded from source distributions and must not be linked as normative references from
public APIs, Schemas, design documents, or user instructions.
